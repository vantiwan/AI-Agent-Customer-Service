# 12530彩铃 · 多 Agent 智能客服与内容生成系统 🚀

本项目是一款专为 **企业/商务/广告彩铃** 场景量身定制的商业级大模型应用。基于 **扣子 (Coze)** 平台开发，并采用先进的 **多 Agent（Multi-Agent）群组架构**。系统现已成功接入微信公众号 **【12530彩铃】** 并投入常态化商业运营，实现了“公域拦截-智能答疑-私域引流-内容生成”的全链路自动化闭环。

🌐 **项目在线体验 Demo**: [点击此处实时体验客服悬浮球](https://vantiwan.github.io/AI-Agent-Customer-Service/)

## 🎯 业务痛点与商业价值

* **传统痛点**：企业/个人彩铃业务咨询量大且问题集中（资费、办理流程、运营商审核标准等），人工客服 7x24 小时接待成本高；同时，从“咨询”到“文案创作”再到“音频合成”的业务链条长，极易流失客户。
* **核心解法**：通过打造具备“顾问式营销思维”的 AI Agent，标准化解答产品信息、过滤低效流量，并将高意向客户精准引导至专属微信客服。同时引入内容生成 Agent，缩短交付周期。
* **商业成效**：降低一线客服 70%+ 的重复工作量，实现公众号生态内的 24h 无缝获客与高转化引流。

## ⚙️ 多 Agent 系统架构分工

本系统打破了传统单体 Bot 的能力瓶颈，针对彩铃业务的垂直需求，设计了三个独立工作且未来协同的多 Agent 矩阵：

| Agent 名称 | 当前状态 | 核心职责与核心能力 |
| :--- | :--- | :--- |
| **1. 彩铃业务咨询 Agent** | 🟢 **已上线运营** | **流量承接与私域转化**：熟知企业/个人彩铃政策，基于知识库进行精准答疑，识别高意向用户并自动输出微信客服卡片引导转化。 |
| **2. 企业彩铃文案编辑 Agent**| 🟡 **近期上线/独立调试中** | **创意内容生成**：根据客户的行业特质、宣传痛点与品牌形象，一键智能生成专业、吸睛、符合广电审核标准的彩铃定制宣传文案。 |
| **3. AI 配音生成 Agent** | 🟡 **近期上线/独立调试中** | **多模态音频合成**：无缝对接文案输出，提供多语种、多商用音色选择，实现从文本到彩铃成品音频的自动化一键合成与试听。 |

## 🛠️ 技术实现路径

* **核心平台**：扣子 (Coze) 企业级 Agent 编排引擎。
* **交互方式**：前端基于 **Coze Chat SDK** 深度定制，实现了多端自适应的流式响应（Streaming）聊天悬浮窗。
* **核心能力**：
    * **结构化 Prompt 演练**：精准控制 AI 的服务语气、企业人设与商务边界，拒绝大模型幻觉。
    * **知识库路由（RAG）**：精准匹配企业内部产品白皮书与最新资费政策，保障技术和业务的合规性。
    * **多工作流（Workflow）编排**：设计了特定的意向识别与用户线索收集工作流，提高引流精准度。

## 🚀 项目未来迭代规划（Roadmap）

为了攻克从“单兵作战”到“团队协同”的跨越，项目制定了明确的三步走迭代计划，重点解决多 Agent 场景下的状态流转与上下文同步：

### 📍 阶段一：单体 Agent 深度调优与公私域联动（当前阶段）
* **知识库（RAG）迭代**：持续收集公众号真实用户的边缘 case，增补个人/企业彩铃在各省份运营商的特殊政策差异，降低大模型幻觉。
* **留存转化路径优化**：在咨询 Agent 中加入动态表单或条件触发器，当用户表现出强意向（如询问“怎么交钱”“怎么开通”）时，更自然地推送微信客服账号信息，精准引导至私域。

### 📍 阶段二：多 Agent 协同流（Multi-Agent Orchestration）编排（核心攻坚）
* **现状与痛点**：目前“企业彩铃文案编辑 Agent”与“AI配音生成 Agent”**已实现分别独立工作**。当下面临的核心课题是在多 Agent 联合场景下进行微调，打通上下文握手与路由分发。
* **全自动交付管线（Pipeline）目标**：
  1. 用户向 **咨询 Agent** 表达定制意向 ➡️ 
  2. **主路由（Master-Router）** 识别到创作需求，无缝将上下文（企业背景、行业、核心卖点）打包传递给 **文案编辑 Agent** ➡️ 
  3. 文案 Agent 生成多版宣传词并交由用户确认 ➡️ 
  4. 确认后自动触发 **AI 配音 Agent** 调用语音合成大模型，一键输出试听音频。

### 📍 阶段三：数据驱动与全链路自动化闭环（长期规划）
* **数据看板建设**：接入微信后台与前端 Demo 的埋点数据，统计用户高频提问热词、AI 答复满意度以及最终的私域引流转化漏斗（Conversion Funnel）。
* **自动化增量训练**：对未成功匹配知识库的用户提问进行聚类分析，实现知识库的半自动更新与迭代，形成持续自进化的服务闭环。
