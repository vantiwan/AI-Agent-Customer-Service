# 🚀 基于 Coze 的全场景智能客服 Agent 解决方案

这是一个旨在解决通用 SaaS 及 B端企业“客户首访流失率高、人工接待成本高”痛点的 AI 智能体客服 Demo。

## 🎯 业务痛点与解决方案
* **痛点**：传统客服系统依赖人工，无法 7x24 小时进行顾问式的产品价值传递，导致潜客线索流失。
* **解法**：通过打造具备“顾问式售卖思维”的 AI Agent，将标准化产品信息、FAQ 导入知识库，并设计多轮引导工作流，自动筛选高意向客户并完成初步话术闭环。

## 🛠️ 技术与实现路径
* **核心平台**：扣子 (Coze)
* **交互方式**：基于 Coze Chat SDK 实现的前端多端自适应悬浮窗
* **核心能力**：
  * **结构化 Prompt 演练**：精准控制 AI 的语气、人设与商务边界。
  * **知识库路由（RAG）**：精准匹配企业产品白皮书，拒绝 AI 幻觉。
